# Skyward 0.5.1.3（小米 15 Pro）

这一版修的是 0.5.1.2 丢掉的几样东西。

## 修好的

- **data 分区打不开**：恢复环境的程序要链系统里的 `libvndksupport.so` 与 `libdl_android.so`，
  少了它们，手机自己的硬件服务（keymint 在内）一启动就退出，data 分区于是一直关着。
  现在起服务之前先把这两个库从已装的系统复制到 `/system/lib64`，再起服务。
  真机上验证过：keymint 注册成功，记住的密码自己解开了 data。
- **双击亮屏**：面板熄灭后留在自家 doze 里，触控控制器继续报点；300 ms 之内、落在 8% 屏宽
  以内的第二下点亮面板。此前面板一熄，触控 IC 跟着挂起，点两下没有反应。
- **预测性返回**：从左边缘往右滑时，下面那一页跟着手指出来，松手落到的那一页已经在玻璃上，
  与系统的手势一致；滑动不到一半就松开，页会弹回去。

## 仍然没接过来的

上游的界面里没有 AVB / vbmeta 页面、没有 Wi-Fi 已保存网络列表与「忘记网络」，
安装脚本长时间没有输出时的提示也还没搬。在此之前，vbmeta 的改动请用安装脚本里的 `avbctl`。

## 版本号

`0.5.1.3`：上游的三段 `0.5.1` 加 fork 的第四段。

刷入后可以在 `adb shell dmesg | grep -i "recovery up"` 里看到 `haotian 0.5.1.3`。

# Skyward 0.5.1.3 (Xiaomi 15 Pro)

This release repairs what 0.5.1.2 lost.

## Fixed

- **The data partition could not be opened**: the recovery's own programs link against
  `libvndksupport.so` and `libdl_android.so` from the installed system, and without them every
  hardware service of the phone — keymint among them — ended as soon as it started, so the data
  partition stayed closed. Both are now copied into `/system/lib64` before the services start.
  Verified on the phone: keymint registered, and the kept credential opened the data partition
  by itself.
- **Double-tap to wake**: the panel stays in its own doze with the touch controller still
  reporting fingers; a second tap within 300 ms and within 8% of the width lights the panel.
  Before, the panel going dark suspended the touch IC, and taps went nowhere.
- **Predictive back**: a swipe in from the left edge now brings the page underneath along with
  the finger, so the page the finger lets go to is already on the glass, as the system's own
  gesture shows it; letting go early puts the page back.

## Not taken yet

Upstream's pages still have no AVB/vbmeta page, no kept-networks list with "forget", and no
notice for an install that has gone quiet. Until then, change vbmeta with `avbctl` from a
script.

## Version

`0.5.1.3`: upstream's three parts `0.5.1` plus the fork's fourth.

After flashing, `adb shell dmesg | grep -i "recovery up"` shows `haotian 0.5.1.3`.
