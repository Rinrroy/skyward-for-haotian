# Skyward 0.5.1.2（小米 15 Pro）

这一版把上游 0.5.1 的界面与安装器整体接了进来，再把 fork 自己的东西一样样搬回去。
界面与安装器从此是上游的，功能是两头合并后的。

## 接过来的上游改动

- **15 种语言的界面**：德、英、西、法、印尼、意、日、波兰、葡（巴西）、俄、土、乌克兰、越、简中、繁中。
  语言在「设置」里切换，首次启动跟随系统语言；时区同样如此。
- **时区页**：可以跟随系统时区，也可以手动挑一个。
- **新的刷写方式**：super 分区的整体镜像、逻辑分区、sparse 镜像，都由安装器按镜像自己写；
  写入前整理分区、写完读回校验。
- **数据分区的备份与恢复**：整分区备份、校验和、以及在全新 data 分区上的恢复；
  内部存储单列为一项；未加密的 data 分区不需要 keymint 就能打开。
- **15 种语言的文字**由 `crates/skyward-ui/locales/` 里的目录表生成，页面上不再有写死的三种语言。

## 保留的 fork 功能

- **记住解锁密码**：设置里打开后，这次解锁的密码（图案/数字/PIN）用 AES-256-GCM 封装在
  `/metadata/skyward/credential`，下次开屏自己试一次；关掉开关立即删除。换一台手机读不出来。
- **常亮显示与双击亮屏**：面板在自家的 doze 里留在玻璃上，时间、电量、槽位与 data 状态每分钟更新；
  双击亮屏只在机型描述里有触控时才出现。
- **两个槽位一起改的 avbctl**：安装脚本里的 `avbctl disable-verification` / `disable-verity`
  会把两个槽位的 vbmeta 一起改，并重算认证块与页脚哈希，而不是只改当前槽位。
- **马达驱动先起来**：启动时把马达驱动的固件放到内核查找的位置，必要时解绑再绑定一次，
  让震动在第一次触摸时就已经可用。
- **ADSP 先起来**：keymint 的 TA 要过 ADSP 才能开，启动时等它 running 再起服务。
- 仍然只描述小米 15 Pro（`devices/haotian.toml`），其它机型的描述不随这个 fork 发布。

## 还没接过来的

上游的界面里没有 AVB / vbmeta 页面、没有 Wi-Fi 已保存网络列表与「忘记网络」，
安装脚本长时间没有输出时的提示也还没搬。这些是这个 fork 下一版要补的；
在此之前，vbmeta 的改动请用安装脚本里的 `avbctl`。

## 版本号

`0.5.1.2`：上游的三段 `0.5.1` 加 fork 的第四段，与上一版 `0.5.1.1` 是同一套编号。

刷入后可以在 `adb shell dmesg | grep -i "recovery up"` 里看到 `haotian 0.5.1.2`。

# Skyward 0.5.1.2 (Xiaomi 15 Pro)

This release takes upstream 0.5.1's pages and installer whole, then moves this fork's own
work back onto them. The pages and the installer are upstream's now; the features are both.

## Upstream, taken

- **Fifteen languages**: German, English, Spanish, French, Indonesian, Italian, Japanese,
  Polish, Portuguese (Brazil), Russian, Turkish, Ukrainian, Vietnamese, Simplified Chinese,
  Traditional Chinese — chosen on the settings page, following the system at first start.
- **The time zone page**, following the system or chosen by hand.
- **The new ways of writing**: a whole super image, logical partitions, sparse images, as the
  installer finds them in what it was given, with the partitions laid out and read back.
- **Backup and restore of the data partition**, whole, with checksums, and into a data
  partition made afresh; internal storage is its own item; an unencrypted data partition
  opens without keymint.
- The fifteen languages come from the catalogues under `crates/skyward-ui/locales/`; no page
  carries three strings any more.

## This fork, kept

- **The remembered screen lock**: once the switch is on, the credential that unlocked the data
  partition is sealed with AES-256-GCM under this phone's serial into
  `/metadata/skyward/credential`, tried by itself at the next start, and forgotten the moment
  the switch is turned off. Another phone cannot read it.
- **Always-on display and double-tap wake**: the panel stays in its own doze with the clock,
  battery, slot and data state on the glass, redrawn each minute. The two-tap switch appears
  only where the phone's description has a touchscreen.
- **An avbctl that changes both slots**: `avbctl disable-verification` and `disable-verity` in
  install scripts change both slots' vbmeta together, recomputing the authentication block and
  the footer hash, rather than only the running slot.
- **The motor's driver brought up first**: its firmware is put where the kernel's loader looks
  and the driver is unbound and bound back when its first probe already failed, so the first
  touch feels.
- **The ADSP brought up first**: the keymint TA reaches the secure element over it, so the
  recovery waits for it to run before it starts services.
- Only the Xiaomi 15 Pro is described (`devices/haotian.toml`); other phones' descriptions do
  not ship with this fork.

## Not ported yet

Upstream's pages have no AVB / vbmeta page and no list of kept Wi-Fi networks with a way to
forget one, and the notice that an install script has gone quiet is not there either. Those
are the next release's work; until then, vbmeta is changed with `avbctl` from an install script.

## Version

`0.5.1.2`: upstream's three parts `0.5.1` plus this fork's fourth, the same scheme as `0.5.1.1`.

After flashing, `adb shell dmesg | grep -i "recovery up"` shows `haotian 0.5.1.2`.
